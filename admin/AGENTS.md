# 관리자 화면 지침

관리자 기능은 기존 권한 체크와 POST/GET 흐름을 유지한 채 정리한다.

## 주요 파일

- `index.php`, `menu.php`, `menu2.php`, `admin.css`, `admin-header.php`
- `problem_*.php`, `contest_*.php`, `user_*.php`
- `news_*.php`, `privilege_*.php`, `settings.php`

## 작업 규칙

- 기능을 삭제하지 않는다. 숨김·분류·명칭 변경은 영향 범위를 확인한 뒤 진행한다.
- 위험 기능에는 명확한 이름과 확인 흐름을 둔다. 예: 삭제, 재채점, DB 업데이트, 백업, 파일 관리.
- 학교 운영의 핵심 메뉴인 문제 관리, 대회 관리, 사용자 관리, 권한 관리, 공지 관리, 시스템 설정, 백업 및 유지보수를 우선 노출한다.
- 외부 OJ 가져오기, 레거시 도구, 실험적 기능은 별도 그룹으로 분리한다.
- 카드 남발보다 표, 탭, 명확한 버튼 그룹, 일관된 폼 레이아웃을 우선한다.
- 직접 출력하는 문구는 가능한 `lang/ko.php` 또는 공통 문구를 재사용한다. 직접 번역할 때는 루트 `AGENTS.md`의 공통 용어를 따른다.
- 수정 후 관리자 메뉴 링크, target 동작, 권한 체크가 유지되는지 확인한다.
